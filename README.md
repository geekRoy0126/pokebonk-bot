# PokéBonk 自动辅助

PokéBonk 电脑版的挂机刷局辅助：自动走位、收集、抓宝可梦、选升级卡、开局结束自动下一局。


---

## 一、下载

1. 打开右边的 **Releases**，下载最新的 **`bot.zip`**
   （或者点绿色的 **Code → Download ZIP**）。
2. **先别解压！** 右键 zip → **属性** → 底部勾选 **「解除锁定」** → 确定。
   不做这一步，Windows 可能弹出「智能应用控制已阻止…」。
3. 把 zip 解压到任意文件夹。

## 二、运行

1. 如果 PokéBonk 已经开着，**先完全关掉**。
2. 双击 **`start.bat`**。
3. 第一次运行会：
   - **检查 Node.js**：没装的话会问 `Install Node.js LTS automatically now [Y,N]?`，按 **Y** 自动安装。
   - **自动找游戏**：找不到时，把 `PokeBonk.exe`（或游戏文件夹）**拖进黑色窗口**，按回车。找到后会记住，下次直接打开。
4. 游戏自动启动，右上角出现 **「PokéBonk 辅助」** 面板，就成功了。

> 黑色窗口**不要关**，关了辅助就停了。

## 三、怎么用

开一局离线游戏，辅助会自动开始。面板上每一项都能勾选开关，设置会自动保存。

| 快捷键 | 作用 |
| --- | --- |
| F6 | 自动跳跃 开/关 |
| F7 | 折叠面板 |
| F8 | 自动走位 开/关 |
| F9 | 自动选升级卡 开/关 |
| F10 | 结束后自动下一局 开/关 |

**它会做什么（大致优先级）：**

1. 抓宝可梦（精灵球 / 友友球），队伍满了不再抓支援头目
2. 技能够了去融合（不会合成 MissingNo）
3. 剩 3 分钟召唤首领、进传送门
4. 大招好了冲进怪群放，放完跑开
5. 祭坛、卡比兽、精灵球、诅咒、道馆挑战、化石等互动点（不开金色/紫色祭坛）
6. 金币、经验、道具
7. 升级卡 / 祝福：先学技能 → 金钱经验 → 稀有度 → 伤害 → 速度 → 保命

**面板里的数字：**

- **清怪**：15 米内怪物达到这个数量，就先在外圈绕着清怪
- **互动点倍率**：越大越爱去拿地图上的互动点
- **打怪优先级 / 经验球优先级**：越大越爱打怪 / 捡经验

## 四、常见问题

**「'node' 不是内部或外部命令」**
用新版的 `start.bat`，它会自动安装 Node.js。也可以自己到 <https://nodejs.org> 装 LTS 版本。

**「智能应用控制已阻止可能不安全的文件」**
回到第一步：右键 zip → 属性 → 解除锁定，再重新解压。
或者在文件夹地址栏输入 `cmd` 回车，运行 `node launcher.mjs`。

**被杀毒软件拦截**
辅助通过调试端口控制游戏，有些杀毒软件会误报。把辅助所在的文件夹加入杀毒软件的信任 / 排除列表即可。

**连不上游戏页面**
先把 PokéBonk 完全关掉（包括任务管理器里的残留进程），再双击 `start.bat`。

**游戏换了位置**
不用管，会自动重新查找。也可以删掉文件夹里的 `game-path.txt` 强制重新查找。

**面板显示「已暂停」**
当前是排名局 / 合作局 / 对战局，辅助不会运行。换成离线局即可。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `start.bat` | 双击这个启动 |
| `launcher.mjs` | 启动器：找游戏、带调试端口启动、注入辅助 |
| `bot.js` | 辅助本体（走位、选卡、面板） |
| `game-path.txt` | 自动生成，记住游戏位置 |

辅助不修改任何游戏文件，关掉黑色窗口、重启游戏就完全恢复原样。
